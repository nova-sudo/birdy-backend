2. AI Chat Pipeline — Detailed Flow (MCP dual-dispatch)

sequenceDiagram
    participant U as User (Frontend)
    participant R as POST /api/chat
    participant S as Session Store
    participant O as Orchestrator
    participant P as LLM Provider
    participant MC as MCP Client
    participant MS as MCP Server (/mcp)
    participant T as Tool Registry (fallback)
    participant DB as MongoDB
    participant M as Meta API

    U->>R: { message, session_id }
    R->>S: get_or_create(session_id, user_id)
    S-->>R: (session_id, history[])

    R->>O: run_chat(provider, registry, db, user_id, msg, session_id)

    Note over O: Append system prompt + user message to history
    O->>MC: mint short-lived internal JWT for user_id
    MC->>MS: list_tools() (Bearer token, ASGI transport)
    MS-->>MC: 26 tool schemas (JWTVerifier already ran)

    loop Max 6 iterations (5 with tools + 1 final)
        O->>P: chat_completion(messages, tool_schemas, temp=0.3)
        P-->>O: ProviderResponse { content, tool_calls[] }

        alt No tool calls
            O->>S: save_messages(session_id, history)
            O-->>R: { reply, tools_used, session_id }
            R-->>U: ChatResponse JSON
        else Has tool calls
            loop For each tool_call
                alt Tool is MCP-migrated (all 26 tools)
                    O->>MC: call_mcp_tool(name, args)
                    MC->>MS: tools/call (same auth path as external MCP clients)
                    MS->>DB: Query / write (facebook_cache, ghl_contacts, alerts, ...)
                    DB-->>MS: Document(s)
                    MS-->>MC: CallToolResult (structured content)
                    MC-->>O: JSON string (truncated to 8000 chars, error-shaped on failure)
                else MCP connection failed — fallback
                    O->>T: execute(tool_name, db=db, user_id=user_id, **args)
                    T->>DB: Same query, direct in-process call
                    DB-->>T: Document(s)
                    T-->>O: JSON string (identical truncation/error contract)
                end
                Note over O: Append tool result to history
            end
        end
    end
