2. AI Chat Pipeline — Detailed Flow

sequenceDiagram
    participant U as User (Frontend)
    participant R as POST /api/chat
    participant S as Session Store
    participant O as Orchestrator
    participant P as LLM Provider
    participant T as Tool Registry
    participant DB as MongoDB
    participant M as Meta API

    U->>R: { message, session_id }
    R->>S: get_or_create(session_id, user_id)
    S-->>R: (session_id, history[])

    R->>O: run_chat(provider, registry, db, user_id, msg, session_id)

    Note over O: Append system prompt + user message to history

    loop Max 6 iterations (5 with tools + 1 final)
        O->>P: chat_completion(messages, tool_schemas, temp=0.3)
        P-->>O: ProviderResponse { content, tool_calls[] }

        alt No tool calls
            O->>S: save_messages(session_id, history)
            O-->>R: { reply, tools_used, session_id }
            R-->>U: ChatResponse JSON
        else Has tool calls
            loop For each tool_call
                O->>T: execute(tool_name, db=db, user_id=user_id, **args)

                alt Cached tool (meta_tools, ghl_tools, etc.)
                    T->>DB: Query facebook_cache / ghl_contacts / alerts
                    DB-->>T: Document(s)
                    Note over T: enrich() adds CPL, conversion_rate, frequency
                else Live Meta tool
                    T->>DB: Get access_token from users collection
                    T->>M: GET /v23.0/{account}/campaigns?time_range=...
                    M-->>T: Campaign + adset + ad data
                    Note over T: enrich() adds derived metrics
                else Alert write tool
                    T->>DB: Insert/update alerts collection
                    DB-->>T: Success
                end

                T-->>O: JSON string (truncated to 8000 chars)
                Note over O: Append tool result to history
            end
        end
    end
